# На сверку владельцу

Пункты, которые скилы **не додумывают**: решение — по официальному источнику или по вычитке носителем языка. Закрытый пункт — PR с правкой скила, тестами и ссылкой на источник.

## uz-docs / uz-ids

- [ ] **ПИНФЛ (JShShIR):** официальный документ со структурой 14 цифр (что значит каждая позиция) и алгоритмом контрольной цифры, если он есть. Пока проверяется только «14 цифр».
- [ ] **СТИР (ИНН):** официальный источник по структуре 9 цифр и контрольной цифре. Пока проверяется только «9 цифр».
- [ ] **Паспорт / ID-карта:** подтвердить формат «2 латинские буквы + 7 цифр» для всех действующих документов (паспорт старого образца, биометрический, ID-карта). Список серий в скил не вносим.

## uz-finance / uzs-amounts

- [ ] **Сумма прописью по-узбекски:** вычитка носителем. Сейчас сотни и тысячи пишутся с «bir» (`bir yuz`, `bir ming`), валюта — `soʻm … tiyin` без мн. числа. Как принято в платёжных документах?
- [ ] **Сумма прописью по-русски:** формы «сум / сума / сумов», «тийин / тийина / тийинов» и формат `… сумов 00 тийинов` — так ли в платёжных документах?
